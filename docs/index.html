How this is selected

  • Main page = registered trials only. Anything without a trial or published data appears only on the claims page.
  • No me-too drugs. A drug program is tracked only if it is first in class (a new mechanism or target) or aimed at aging itself. Devices are tracked as devices.
  • Programs are curated; trials are not. Each program carries a registry query and a match rule, and its trials are whatever the registry returns that pass the rule. Programs aimed at aging must also name aging in the trial's title, conditions or keywords (\b(aging|ageing|older adults?|elderly|frailty|senescen\w*|longevity|healthspan|geroscience|age-related)\b).
  • Example: Precision Neuroscience is not on the board because it has no registered trial yet.
